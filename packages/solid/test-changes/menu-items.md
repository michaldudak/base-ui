# Test changes: menu-items

- `item/MenuItem.test.tsx`, "perf: does not rerender menu items unnecessarily": React re-render counts rewritten to the Solid equivalent. The `LoggingRoot` forwardRef component became a render function that calls the spy; after ArrowDown the test waits for item 2 to get `data-highlighted`, checks item 1 lost it, and expects every spy to have 0 calls (React expected 2 for items 1 and 2). Solid runs a render function once and updates the element in place. Still skipped in JSDOM, as in React.
- `checkbox-item/MenuCheckboxItem.test.tsx`, "perf: does not rerender menu items unnecessarily": same rewrite as in MenuItem.
- `radio-item/MenuRadioItem.test.tsx`, "perf: does not rerender menu items unnecessarily": same rewrite as in MenuItem.
- `radio-item/MenuRadioItem.test.tsx`, conformance fixture (`testRadioGroupContext`): `value` and `disabled` are accessors (`() => '0'`, `() => false`), following guide 3.5 (context fields that change are accessors). This assumes that is the shape of the Solid `MenuRadioGroupContext`.
- `link-item/MenuLinkItem.test.tsx`, "react-router <Link> activates with Enter and Space": skipped (`it.skip`, was `it.skipIf(isJSDOM)`), needs react-router. The test is about router navigation, not the `render` prop. Body kept as a block comment, translated to Solid syntax, together with the `One`, `Two` and `LocationDisplay` helpers.
- `link-item/MenuLinkItem.test.tsx`, "does not navigate when Space is pressed during an active typeahead session": skipped for the same reason, body kept as a block comment.
- `group-label/MenuGroupLabel.test.tsx`, "does not let an older label cleanup clear a newer label": the `Test` component's `{labels !== 'new' && <X key="old" />}` became `<Show when={props.labels !== 'new'}>`, and `rerender(<Test labels="both" />)` became `setProps({ labels: 'both' })`. The `key` props are gone, since `<Show>` keeps each label at its own position.
- `list/MenuList.test.tsx`, "does not point an inactive trigger at the list" and "does not re-render an inactive trigger when the list mounts": `useRefWithInit(() => Menu.createHandle()).current` became `Menu.createHandle()`, since the component body runs once.
